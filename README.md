# E-Commerce Sales Analysis (SQL Project)

##  Overview
An end-to-end data analysis project using **Microsoft SQL Server (SSMS)** on an e-commerce dataset to evaluate sales performance, shipping efficiency, and revenue loss.

## Tools & Concepts
- **Tool:** SQL Server Management Studio (SSMS)
- **SQL Functions:** `INNER JOIN`, `GROUP BY`, `TOP`, `TRY_CAST`, `CASE WHEN`, `SUM`, `COUNT`, `AVG`

##  Analytical Scope
1. **Top 5 Products:** Identified best-selling products by order volume and revenue.
2. **Regional Performance:** Analyzed total sales and unique orders across regions.
3. **Payment Modes:** Calculated order counts, net sales, and Average Order Value (AOV).
4. **Logistics & Delays:** Tracked shipping methods, average costs, and delayed deliveries.
5. **Loss Analysis:** Measured revenue lost due to returned orders by reason.
